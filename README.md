# Synapse RAG

This project is set up for collaborative development.

## Tech Stack & Architecture

We are currently building out the initial infrastructure. Here are the core technologies we have chosen:

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Full-stack)
- **Language:** TypeScript
- **Styling:** Vanilla CSS (Modern, premium aesthetics with micro-animations)
- **Authentication:** [NextAuth.js](https://next-auth.js.org/) (100% open-source, zero-cost, storing users in our DB)
- **Database:** [PostgreSQL](https://www.postgresql.org/) (Using `pgvector` for RAG embeddings and storing documents + users)
- **ORM:** [Prisma](https://www.prisma.io/)

## Current Status

We are in the process of initializing the Next.js application, configuring the Prisma schema for PostgreSQL, and setting up the NextAuth integration.
